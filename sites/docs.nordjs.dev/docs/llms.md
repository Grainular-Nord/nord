# Large Language Model Documentation

Nørd production builds provide optimized documentation structures for Large Language Models (LLMs) and AI agents. We adhere to the standard [llms.txt](https://llmstxt.org/) convention so AI assistants can ingest the documentation without parsing HTML.

The following files are intended to be available from the documentation root:

- [`/llms.txt`](/llms.txt): A concise summary of the framework, key concepts, and high-level API reference.
- [`/llms-full.txt`](/llms-full.txt): The complete documentation, including detailed guides, API signatures, and examples.
