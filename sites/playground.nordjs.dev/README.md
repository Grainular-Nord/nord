# playground.nordjs.dev

Nørd's interactive learning environment, statically generated by Aurora. Each lesson is a real, editable TypeScript + Nørd project that runs live in the browser next to the lesson's Markdown — no bundler or install step, just native ES modules and an import map pointing at a CDN.

To install dependencies:

```bash
bun install
```

To start the development server:

```bash
bun run playground:dev
```

Create a production build with `bun run playground:build` and serve it locally with `bun run playground:preview`.
